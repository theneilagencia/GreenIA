# Registro das operações de tratamento (resumo)

Documento fictício, para demonstração.

O registro das operações de tratamento fica na pasta de Compliance e é revisado a cada seis meses. Cada operação descreve a finalidade, a base legal, as categorias de dados, os operadores envolvidos e o prazo de retenção.

As evidências de treinamento (listas de presença e certificados) ficam na pasta de Treinamentos, organizadas por mês.
